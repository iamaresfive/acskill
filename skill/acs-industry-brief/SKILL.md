# 公考培训行业动态简报

面向行业从业者，交付事实可追溯、判断有边界的单页HTML。采用固定三节和蓝／琥珀／红版式，不把某日样例的新闻、数字或判断固化成事实。

## 1. 确定本期与检索

- 明确日期时按指定日期；“今天”用当前用户时区的日期，默认Asia/Shanghai。默认三节，不追问希望看哪方面。只有已有上下文明确为本简报时，单说“简报”才触发；其他简报先按实际主题路由。
- 先读[采编与证据规则](references/editorial.md)。主体取当日及前24—48小时；不足可取近3—5日未覆盖的重要事项，标真实发布日期。能取得近7日历史简报时按事件去重，标明续报／更正；没有历史材料如实说明，不声称已排除重复。
- 做4—6组发现检索，覆盖监管执法、招录政策、上市公司、司法风险、资质广告、行业舆情；相近方向可合并。发现检索的组数不是原文核验的次数上限；有疑点再补核。
- 搜索只找线索。逐条打开原文，核对主体、真实发布日、原文关键句、适用对象。政府／法院／交易所及公司披露优先；可信媒体全文可以支持“媒体报道了什么”，不能伪装已读原披露。只读到摘要或单一匿名帖的留在候选，不进正式事实卡。
- 使用当前环境可用的搜索、网页或PDF工具。公众号必要时使用可用的`acs-read-wechat-article`；没有该Skill则用可用工具并说明覆盖。网络或登录受阻时仅保留受阻条目，其他合格条目继续；不改全局代理、不绕过验证、不用搜索摘要补写原文。

## 2. 编选与人工审定

- 固定三节：监管与政策、市场与同业、网络舆情。纯报名日程和考试安排不凑版；真正涉及政策变化的归第一节，报考人数等行业数据可归第二节。考试组织方的纯考务通知不是同业动作。
- 目标7—9条，通常8条；质量和时间窗优先。少于7条时写清检索范围及缺口，允许某节为0，不用旧闻／传闻补足。多于9条优先筛选，用户另有数量要求时按本次要求处理，不暗改模板规则。
- 事实、研判、口径提示分开。原文中的关键短句可直接引述；正文其余用忠实转述，遵守来源引用长度限制。每条附可点击原始来源，媒体转引明确标出层级。
- 不给任何单一客户机构出建议，不用“你、您、咱们、贵司”等第二人称，不假设读者业务。行业研判不是个人IP文章，不调用内容商业化框架强加产品引导。
- 不设AI落地专题卡；只有政策原文确实涉及AI时才按政策事项报道，不把财报里提及AI转成AI专题。
- 比较类强断言先核同主体、同事项近3—5个同类周期；未核完整就去掉“首次、最严、首个”等断言。连“较上届变化”也必须实际读过上届，不能用降级措辞掩盖未比较。
- 人工逐条审定研判和数据边界后，按[输入与交付格式](references/input-format.md)写本期JSON。`editor_reviewed=true`只是执行者的审阅记录，不是联网验真结果；没有实际阅读不能填已核。

## 3. 生成、检查、交付

```bash
python3 scripts/brief.py render /绝对路径/本期输入.json --output-dir /绝对路径/本次任务目录
python3 scripts/brief.py check /绝对路径/YYYY-MM-DD-公考培训行业动态简报.html --input /绝对路径/本期输入.json
```

- 脚本使用Python标准库，离线生成HTML及同批证据JSON，拒绝覆盖；不联网、截图、绘图或启动外部应用。输入字符串按文本转义，不接受自由HTML。
- 安装位置不影响执行；脚本保护Skill包本身及按结构识别出的知识库，不按固定父目录层级推断。用户指定输出目录优先；未指定时选择当前环境实际可写的任务目录。云端沿其任务工作目录；同名成品已存在时另建版本，不覆盖。
- 保留v3 CSS数值，三节颜色和最大宽度880px、事实段14px不改。模板元信息、关键词、计数和日期使用指定span；不接受正文任意span。来源链接放在既有来源／口径区域，不生成图。
- 检查脚本核对字段、日期、来源链接、结构、禁用表达及输入与成品一致；不能证明原文真实、引文语义、财报口径或研判成立。出现历史比较／强因果提示时逐条人工处理，不能仅凭脚本PASS交付。
- 直接展示可用HTML或提供实际文件入口，不用PNG、长图替代。交付简述今日最值得记的1—2件事、口径提醒／修正点、与前期衔接及真实缺口。无更正写“本期无修正”；未核既往版本则说明覆盖范围，不称从未出错。
- 已有简报复核时读其完整正文和证据，指出具体缺口；只有要求改版才另出版本。脚本检查现有HTML不等于事实审定，不修改原样例。

制作请求只授权本期检索与库外成品，不自动定时、外发、改线上教程或写知识库。另行明确入库时依目标库规则保存原件与必要知识页；本Skill不另造授权流程。
