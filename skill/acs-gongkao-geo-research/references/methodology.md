# GEO 调研方法论

## 1. 定义与观察模式

本 Skill 中，GEO 指一个机构、品牌或老师/IP 在生成式 AI、AI 搜索及传统搜索与生成式搜索融合环境中，被系统发现、理解、确认、召回和引用的能力。

默认模式为 `public-web-proxy`：通过调查日可公开检索、抓取和复核的网页，构建 GEO 可见性代理指标。它衡量公开语料与实体关系的可用程度，不等于特定模型实际答案。

只有对多个生成式搜索引擎使用同一题池、记录时间与原始回答时，才能增加 `multi-engine sampling`。两类结果分别呈现：

- 公开网页代理：页面、来源、实体和问题覆盖。
- 多引擎采样：指定引擎、指定时间、指定问句下的实际回答快照。

任何模式均须声明：GEO 观察指数不是教学实力、市场份额、经营规模、真实口碑或大模型官方推荐榜。

## 2. 查询口径

### Generic Query

不含机构名称，用于测量泛词召回、地域/产品/专项/决策占位和概念绑定。Query Coverage 主要由此类查询支持。

### Brand Query

包含机构、品牌或老师名称，用于确认官网、主体、老师、学科、产品、校区、基地、联系方式和第三方关系。品牌词可检索不代表泛问题下会被召回。

### Query → Page

记录每个问题由哪些可抓取页面直接回答。高质量矩阵应覆盖真实用户问题，并有稳定 URL、清楚标题、正文答案、更新时间和来源关系，而不是同一营销稿换标题铺量。

## 3. 五维 GEO 观察指数

总分 100，单项不得超过权重。

### Query Coverage｜30

综合全部 Generic Queries，观察：

- 综合推荐、地域、产品、专项、决策五组是否被覆盖；
- 在不输入品牌词时是否出现；
- 是否形成 Query → Page 内容矩阵；
- 是否只靠品牌词或同一篇软文被找到。

参考锚点：

- 0—5：几乎只能品牌词检索；
- 6—12：少量泛词偶发出现，覆盖单一；
- 13—18：覆盖多个组别，但稳定性或页面质量一般；
- 19—24：多数核心问题有可复核占位；
- 25—30：覆盖广、跨组稳定，且有明确 Query → Page 资产。

### Entity Clarity｜25

观察机器能否确认品牌、公司/组织、地区、校区、老师、老师—学科、课程、考试类型、基地、历史和联系方式，重点检查：

```text
Brand → Teacher → Subject → Product → Location
```

参考锚点：

- 0—5：主体难确认或同名污染严重；
- 6—12：品牌存在，但人物、产品或地域关系断裂；
- 13—18：主要关系可确认，仍有关键缺口；
- 19—22：核心实体链完整，跨页面一致；
- 23—25：实体链完整、规范、稳定且有外部互证。

### External Diversity｜20

统计独立域名、跨平台来源和高质量第三方验证；同时评估这些来源是否真正独立。Own Media 与 Earned Media 分开，转载同稿去重。

参考锚点：

- 0—4：几乎全部第一方或聚合软文；
- 5—9：少量外部来源，独立性弱；
- 10—14：多个独立域名和部分可靠外证；
- 15—17：来源类型与主体多样，关键关系有互证；
- 18—20：高质量、近期、跨主体独立验证充分。

同时单列 `Independent Evidence Confidence`，避免软文铺量抬高本项。

### Concept Ownership｜15

判断某一专业问题能否稳定指向某品牌或老师。强关系应明确、专业、反复出现，并被多个独立来源确认。`某机构 = 公考培训` 过宽，不算强占位。

参考锚点：

- 0—3：无清晰专业概念；
- 4—7：第一方提出概念，但外部连接弱；
- 8—11：一至多个专业概念形成重复绑定；
- 12—13：核心概念跨平台、跨来源稳定；
- 14—15：在高价值细分问题上接近默认答案。

### Freshness｜10

以调查日为基准观察最近 12 个月，并单列 30/90/180/365 天窗口：

- 当前考试年度课程或考情是否更新；
- 官网、账号、老师/IP 是否持续输出；
- 旧页面是否仍可访问并保持准确。

旧内容可以证明历史实体，但不能替代当前活跃度。

## 4. 总分与等级

```text
S   85—100
A+  80—84
A   70—79
A-  65—69
B+  60—64
B   50—59
B-  45—49
C   <45
```

使用 `scripts/score_geo.py` 计算。分数相同或接近时优先按证据置信度解释，不强行制造精确名次；60 分以下机构之间尤其不要过度解释 1—2 分差异。

## 5. Evidence Confidence

- `High`：官方实体清楚，有多个独立域名、高质量外证和近期内容。
- `Medium`：官方实体清楚，但独立来源或近期覆盖有限。
- `Low`：证据主要来自软文/第一方，搜索稀疏，或主体关系难确认。

置信度不直接加减分，但决定结论语气和排名可解释程度。

## 6. Entity Graph

逐家建立：

```text
Brand
→ Company / Organization
→ Founder
→ Teacher / Expert
→ Subject
→ Exam Type
→ Course / Product
→ Campus / Base
→ City / Region
→ Results / Cases
→ Media / Platform
→ External Citation
```

每条边记录来源和确定性。第一方只能证明“机构如何自我描述”；成绩、通过率、合作和荣誉等需独立验证后才能升级为确认事实。

## 7. Own Media 与 Earned Media

- `Own Media`：官网、官方课程页、官方账号、机构控制的内容矩阵。
- `Earned Media`：机构无法直接控制的政府、高校、媒体、同行、用户或专业主体自然引用。

付费发布、站群转载或以机构名义运营的“第三方账号”不算独立 Earned Media。

## 8. Concept Ownership 与空白机会

从地区、城市、县区、选岗、待遇、基地班、考试类型、考试阶段、题型、人群、老师、机构选择、产品选择和政策变化组合真实问题。对每个概念记录：

- 当前强势主体；
- 第二梯队；
- 竞争强度；
- 证据健康度；
- 是否存在“尚无默认答案”的机会。

机会按 A 优先抢占、B 可系统布局、C 红海分层。不要把搜索量未知的普通关键词直接包装成商业机会。

## 9. 时间窗口与可比性

- 始终记录观察日期、查询时间、使用通道、题池版本和范围。
- 一次搜索是快照，不代表长期稳定。
- 历史比较仅在样本、题池、评分口径、采样环境和时间窗口可比时计算变化；否则并列展示，不制造趋势。
- “本次未检索到”只表示本次范围内未发现，不等于互联网绝对不存在。

## 10. 研究局限

至少说明：

- 网页代理与真实 AI 回答的差别；
- 搜索个性化、地域和时间波动；
- 未覆盖的平台、登录墙和不可抓取内容；
- 人工评分权重及敏感性；
- 机构自述与独立验证的边界；
- 对象池、题池和城市覆盖范围；
- 未解决的同名主体或归属疑点。
