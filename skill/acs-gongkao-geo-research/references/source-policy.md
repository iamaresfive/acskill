# 来源、证据与引用政策 v2.1

## 1. 证据等级

### A1｜高质量独立验证

政府、高校、监管机构、交易所、上市公司公告、权威数据库和高可信第三方正式来源。

A1 只能支持页面直接陈述的事件、身份或关系。高校讲座只能证明该次活动、参与主体与时间；政府采购只能证明对应项目。不得泛化为“官方认可该机构总体能力”。

### A2｜机构第一方

官网、官方课程页、官方账号、官方招生页。可确认机构自我定位、老师、产品、地址、课程和自述历史。

### B｜稳定实名平台

B站、知乎实名长期账号、播客、可确认身份的老师内容等。用于专家实体、主题和跨平台存在。

### C｜营销、榜单、软文与聚合

SEO 文章、无方法的“十大机构排名”、聚合转载、机构控制分发内容。只证明 GEO 语料存在，不能证明市场排名、教学效果或真实口碑。

## 2. 搜索与核验

- 搜索摘要只作发现线索；重要结论打开原页面。
- 动态事实记录 `published_date` 与 `accessed_date`。
- 优先顺序：原始来源 > 高质量第三方 > 稳定平台 > 聚合页 > 搜索摘要。
- 登录墙、微信封闭页、短视频不可抓取页应记录为研究局限，不编造访问结果。

## 3. 独立性与重复

- 同一稿件多站转载，只算一个内容源。
- 同一控制主体的多个账号可证明跨平台存在，但不能算多个独立验证主体。
- 同 URL 支持多个实体/关系时可以多行保留，但必须填 `duplicate_group`、`duplicate_reason`、`review_status=reviewed`、`counting_scope`。
- `counting_scope=ignored` 的 Evidence 不进入独立域名、Authority Index 或多样性计数。

## 4. 陈述类型

- `确认事实` / `fact`
- `机构自述` / `institution-claim`
- `代理指标` / `proxy-metric`
- `分析推断` / `analysis`

页面数、粉丝量、播放量、搜索命中不能直接推导市场份额、营收、教学效果或长期 GEO 能力。

## 5. 事实敏感项

成立时间、法律主体、地址、校区、创始人、老师任职、产品、收费、合作、处罚、诉讼、上岸率、学员量等必须有直接来源，必要时交叉核验。

负面事实必须给时间、主体、事实范围和来源，不把单一投诉概括为普遍事实。

## 6. 对评分和 Authority 的约束

- A2 可支持 Entity Clarity，但缺外证时不能被包装为高 Authority。
- B 可支持 Expert Entity 和 Concept 持续性，但必须确认账号身份。
- C 可证明主动铺量，但对 External Diversity / Authority 大幅折价。
- 只有 Verification 品牌词命中、没有 Institution Measurement 命中的机构，不得获得高 Query Coverage。
- 指定关注主体不影响 Source Grade 或 Evidence Confidence。
- IP 粉丝量、播放量不直接进入机构总分。
