# v2.1.1 稳定性、召回完整性与报告契约补丁

本文件说明 `acs-gongkao-geo-research` 从 v2.1 到 v2.1.1 的修复边界。它是 bug-fix / completeness patch，不是评分模型重构。

## 1. 为什么需要 v2.1.1

v2.1 在全新广东环境实测中暴露了四类问题：

1. 输出目录、派生字段等工程环节会迫使执行者重跑或手工补数；
2. 六路 Discovery + Semantic Coverage 仍可能漏掉本土机构、工作室、基地班、老师型品牌与平台原生 IP；
3. 上游已经执行 IP Measurement、已经存在 evidence-insufficient 候选，但 Report Model / Renderer 可能把这些信息吞掉；
4. HTML 把 A4 版式直接套在浏览器，固定宽 SVG 与长文本宽表容易溢出、错位。

v2.1.1 的目标是：**找得更完整、数据不丢、没进榜的原因说得清、报告在不同媒介里排得稳定。**

## 2. 不做什么

v2.1.1 不改变五维权重：

- Query Coverage /30
- Entity Clarity /25
- External Diversity /20
- Concept Ownership /15
- Freshness /10

不允许为了任何已知机构、IP或地区调分；也不把本土、用户指定、粉丝量或平台热度直接换成分数。

自有域名集中度只形成解释指标 `Owned Source Dependency Ratio`，暂不进入总分。是否改变评分模型必须放到后续方法论版本单独回归。

## 3. 输出目录幂等

所有 Chart / Renderer 使用 `scripts/fs_utils.py::ensure_directory()`：

- 路径不存在：创建；
- 已存在且是目录：直接继续；
- 已存在但其实是文件：明确报错；
- 目录不可写：明确报权限错误；
- 短暂并发竞争：有限重试。

这比机械替换 `Path.mkdir()` 更重要，因为 PermissionError 可能来自权限、路径类型、沙箱映射或并发，而不仅是“目录已存在”。

## 4. 派生字段所有权

`score_geo.py --run-dir` 必须自动从当前 Run 派生：

- `generic_hits`
- `generic_queries`
- `brand_hits`
- `evidence_count`
- `independent_domains`

`evidence_count` 按 `entity_id` 聚合 `evidence.csv`，`counting_scope=ignored` 不计。执行者不应手工补数来迎合 validator。

## 5. Local Ecosystem Recall Audit

六路 Discovery 继续保留，但地区全景在 Candidate Freeze 前必须再覆盖三组通用语义主题：

### `local-institution-ecosystem`

用于发现本土机构、工作室、基地班、地市型品牌、老师型机构。查询应动态组合地区、主要城市、考试垂类和服务场景，而不是硬编码某省机构名单。

### `local-expert-ip`

从“概念/服务 → 人”反向发现老师和 IP。至少考虑当地适用的申论、行测、面试、选岗、公考规划、事业单位、选调等场景，不能只用一个“老师推荐”总词代替。

### `platform-native-ip`

专门发现先在平台形成影响力、再关联机构/概念的 Expert Entity。根据公开可访问性检查抖音、视频号、B站、小红书、知乎、微博等。平台不可访问时记录限制，不得伪造结果。

这三组的作用是防止“标准考试词已经搜完，但真实本土生态仍被漏掉”。

## 6. 第三道 Freeze Gate

地区全景从双门禁升级为三门禁：

```text
Semantic Coverage Gate
+ Saturation Gate
+ Local Ecosystem Completeness Gate
```

只有三者均通过，`candidate_pool_frozen=true` 才合法。

Local Ecosystem Gate 至少要求上述三组语义真实执行并在 `discovery_coverage.csv` 中达到 `covered|no-result-reviewed`，且 `query_count>0`。

## 7. 不得静默消失

新增两条通用校验：

1. Discovery 已解析出 `entity_id` 的主体必须进入 Candidate Pool；
2. 同一未解析名称若在至少两个独立来源域重复出现，必须进入候选/实体解析流程。

Candidate 中的 `evidence-insufficient` 与 `unresolved` 必须进入正式报告的“本土候选观察组”，说明：主体、类型、状态、已确认信息、缺失项与未评分原因。

“没有进正式排名”不再等同于“报告里看不到”。

## 8. IP Measurement 契约

老师/IP 与机构分开 Measurement，不进入机构五维总榜。

老师/IP 可使用 Candidate 状态 `ip-measured`。

只要存在 sampled 的 `measurement_target=ip`：

- `ip_entities.csv` 必须有对应实体；
- `report_model.json` 必须有 `ip_measurement.executed=true`；
- `ip_measurement.rows` 必须可渲染 teacher/IP、关联机构、hits/queries、recall、科目/概念、平台、证据置信度；
- HTML/DOCX/PDF 均必须真正渲染表格，不能只显示“本次已执行 IP Measurement”。

如果没有实际 IP Measurement，只能写 Expert Entity / 可见性观察，不得伪造 IP GEO 排名。

## 9. Report Model 强契约

v2.1.1 的 `report_model.json` 至少包括：

```text
meta
kpis
ranking
scorecards
observation_group
ip_measurement
query_occupancy
charts
appendix
```

`appendix` 必须包括：

- `candidate_status`
- `research_assets`
- `research_audit`

Renderer 必须消费这些数据，而不是让它们停在 JSON 里。

## 10. 商业解释自动归纳

`build_report_model.py` 在 `competition_route` 为空或为占位值时，根据 Recall、Authority、总分与自有来源依赖生成解释型路线，例如：

- 成熟占位型
- SEO/自有资产占位型
- 高权威低召回型
- 主动铺量型
- 全国品牌权重型
- 本地实体待扩召回型
- 本地实体型

`strongest_asset` / `largest_gap` 直接从 `score_details.json` 五维得分和理由生成，禁止整表保留“待归纳”或“由 score_details.json 归纳”。

这些路线只用于解释，不参与五维评分。

## 11. public-web-proxy 边界

`sampling_mode=public-web-proxy` 是公开网页代理观察，不等价于 ChatGPT、DeepSeek、豆包、百度AI等所有产品在所有时间点的真实答案。

偏差来源可能包括：

- SEO站群与聚合榜单；
- 机构自有域名矩阵；
- 搜索引擎索引差异；
- 登录墙与动态页面；
- 短视频/社交平台公开可访问性；
- 个性化和时点变化。

报告必须披露该边界。并行 Agent/采样员时，统一“命中”定义，并随机抽取至少 20% Measurement Query 做第二采样员复判；争议结果回到原始结果上下文。

## 12. HTML 响应式设计

HTML 是屏幕阅读产品，不能把 A4 固定宽度直接套在浏览器。

屏幕端：

- `main` 使用 `max-width`；
- SVG 强制 `width/max-width:100%` 与 `height:auto`；
- 宽表使用 `overflow-x:auto`；
- Scorecard 拆为紧凑排名表 + 机构诊断卡；
- Authority × Recall 使用标签避碰/引导线，降低同点压字。

只有 `@media print` 使用 A4 页边距和分页。

## 13. 四层验收

正式交付不能只看“CSV 没报错”。依次验证：

1. **Research Validation**：Preflight、Query、Entity、Evidence、Score、三道 Freeze Gate；
2. **Report Model Validation**：IP、观察组、Appendix、KPI、Chart Data 完整；
3. **Renderer Validation**：用户选择的格式真实消费关键区块；
4. **Visual QA**：无横向溢出、裁切、标签大面积重叠、坏分页。

自动校验命令：

```bash
python3 scripts/validate_run.py <run-dir> --strict
```

自动校验不替代真实视觉检查。

## 14. 回归

每次修改至少：

```bash
python3 -m py_compile scripts/*.py
python3 scripts/test_v211.py
```

回归必须覆盖：派生字段、预建目录、Local Ecosystem Gate、重复候选不消失、IP 进入 Report Model、观察组披露、自动商业归纳、HTML 响应式契约、三 Renderer，以及广东/山东等非天津地区归一化。

fixture 只能验证规则，不得冒充真实地区 Measurement。
