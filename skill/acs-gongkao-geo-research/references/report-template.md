紧随标题页写明：

> GEO 观察指数衡量公开信息环境中的可发现、可理解、可确认、可召回与可引用能力，不代表教学实力、市场份额、学员效果或任何大模型官方推荐排名。

## 1. 执行摘要

- 本次调查回答的 3—5 个核心问题。
- 覆盖地区、考试、问题数、机构数、来源数、独立域名数和观察日期。
- 最重要的 3—6 条结论，每条注明证据置信度。
- 明确哪些结论为来源事实、机构自述、公开网页代理指标或分析推断。
- 用户只输入地区时，直接回答该地区哪些公考机构排名靠前、为什么靠前、各自短板和可执行的 GEO 优化机会；不引入未被用户点名的委托方主体。
- 用户在前置问询中明确要求纳入自有机构时，即使该机构未被地区 Generic Query 发现，也要将其纳入统一评分和重点分析；不得人为加分，并明确区分自然发现结果与强制纳入。

## 2. 研究口径与边界

- GEO 定义与本报告不评价的事项。
- `public-web-proxy` 与 `multi-engine sampling` 的实际采用情况；两类结果分表展示。
- Generic Query、Brand Query、Own Media、Earned Media 的定义。
- 时间窗口、地域边界、语言、去重规则和主要局限。

## 3. 地区与考试生态

- 地区层级、主要城市和独立招录体系。
- 实际存在的考试、笔面试类型与培训决策场景。
- 本次查询矩阵如何据此适配；不适用问题如何剔除。

## 4. 查询矩阵与候选发现

- 按主题列出 Generic/Brand 查询数量与代表问题。
- 说明调研发现对象、用户指定对象和补充对标对象的发现/选择逻辑。`Candidate`、`Specified`、`Benchmark` 只是内部样本来源，不是机构等级或角色身份。指定模式只包含用户点名主体；只有用户明确要求增加对标时才允许出现 `Benchmark`。
- 对证据不足或无法确认主体的处理方式。
- 地区模式说明候选池如何从整个地区的 Generic Query 中产生，以及领先机构如何按统一口径筛出；用户未点名机构时不得出现 `Specified`。
- 记录用户是否要求强制纳入自有机构。选择纳入时列明准确名称、别名核验与 Generic 命中情况；选择不纳入时不得出现 `Specified`。
- 指定模式列明用户点名的完整集合，报告不得自动加入其他机构或地区领先者；如有对标，必须注明用户的明确要求。

## 5. 证据地图

- A1/A2/B/C 来源数量、独立域名数和重复转载情况。
- 各机构 Own/Earned Media 结构。
- 关键实体关系和仍待核事项。

主排名表默认不展示内部英文 `role`。如果不同样本来源会影响读者理解，在方法或附录增加“入选方式”列，并使用“调研发现 / 用户指定 / 对标补充”，不得直接展示 `Candidate / Specified / Benchmark`。

低置信度或 60 分以下机构不解释 1—2 分和一两个名次的细小差异。若样本不可比，使用分组或“不足以排名”，不要强行给完整榜单。

地区模式下，主表优先展示排名靠前且证据充分的 5—10 家；其余主体放入附录或“待观察”组，不为凑全榜单制造精确名次。

用户明确要求强制纳入的自有机构即使未进入前 5—10，也必须保留在主表和重点分析中，并标明“用户要求纳入；本次 Generic Query 是否自然发现”。此说明不使用英文 `Specified`，也不改变其得分或名次。

数据质量足够时生成：

1. `geo-index.png`：GEO 指数横向柱状图，注明观察日期与置信度。
2. `geo-quadrant.png`：Entity Verifiability × Query Coverage 象限图；点大小可代表独立来源数。

图表数据必须来自 `scores.csv`，不得为视觉效果手工改分。数据不足时省略图表并说明原因。

## 7. 重点机构分析

对主排名中靠前且证据充分的机构逐家使用统一结构；地区模式不要求把所有发现对象都写成长篇分析：

### {institution}

- 实体识别：品牌、主体、创始人、老师/IP、课程、校区/基地。
- 泛词表现：在哪些 Generic Query 中自然出现，哪些仅为品牌词结果。
- 外部证据：独立来源、来源等级、独立域名和重复转载。
- 概念所有权：已建立的稳定关联与尚未占位的概念。
- GEO 模式：品牌权重型、Query 铺量型、实体知识图谱型、Expert/IP 型、地域实体型、主动 GEO 铺量型或证据支持的新模式。
- 五维得分解释：逐维说明证据，不只报总分。
- 风险与局限：机构自述、旧信息、实体歧义、证据不足。
- Evidence Confidence：High / Medium / Low。

## 8. 区域竞争格局

- 全国品牌、本土综合机构、细分机构、老师/IP 型品牌和新主体的相对位置。
- 泛词覆盖、实体可核验性、外部多样性与地域占位的差异。
- 公开网页代理观察与真实多引擎采样结果如有差异，分别解释。

## 9. GEO 模式与实体图谱

- 汇总各机构模式，可多选，不强制一机构一类型。
- 展示核心实体链：品牌 → 主体 → 人物 → 科目/考试 → 产品 → 地域 → 外部引用。
- 区分已确认关系、机构自述关系和分析推断。

## 11. 核心答案、局限与证据附录

- 用短答案回应用户最初的每个问题。
- 列出无法确认、需补采样或不宜比较的事项。
- 附查询清单、评分表、逐条证据、来源等级、访问日期和去重说明。
- 每个重要事实直接附可打开链接或证据编号；搜索摘要仅作线索，不进入最终事实链。

## PDF 默认交付

最终必须生成并直接交付 `report.pdf`，同时保留 `report.md` 和结构化 CSV 供审计。使用可用的 PDF Skill/工具生成 PDF，渲染全部页面后逐页检查中文字体、标题层级、表格分页、来源链接、页码、裁切、重叠和黑块。未通过视觉检查不得交付；不得用 HTML、Markdown 或“请用户自行导出”替代 PDF。

生成前核对摘要、正文和附录中的问题数、Generic/Brand 数、证据数和评分机构数与 CSV 完全一致；核对 `Specified` 仅用于用户实际点名的对象。

## Word 可选交付

用户要求 Word 时，在 PDF 之外额外生成可编辑 `report.docx`，保留真实表格、标题层级、页码、目录与来源链接；使用可用的文档 Skill/工具完成渲染检查。避免用截图代替表格或正文。
