# 公考机构 GEO 调研报告模板

## 标题页

```text
《{地区或研究范围}公考机构 GEO 与 AI 搜索可见性调研》
副标题：基于公开网页代理观察 / 多引擎实测的证据化研究
观察日期：{观察日期}
研究范围：{研究范围}
采样模式：{公开网页代理观察 | 多引擎实测}
IP名师调查：是
IP名师样本数：{名师样本数}
自有机构纳入：{是 | 否}
自有机构名称：{选择“是”时填写；否则省略}
技能版本：v1.1
报告版本：{报告版本}
```

紧随标题页写明：

> GEO 观察指数衡量公开信息环境中的可发现、可理解、可确认、可召回与可引用能力，不代表教学实力、市场份额、学员效果或任何大模型官方推荐排名。

## 1. 执行摘要

- 本次调查回答的 3—5 个核心问题。
- 覆盖地区、考试、问题数、机构数、来源数、独立域名数和观察日期。
- 最重要的 3—6 条结论，每条注明证据置信度。
- 明确哪些结论为来源事实、机构自述、公开网页代理指标或分析推断。
- 用户只输入地区时，直接回答该地区哪些公考机构排名靠前、为什么靠前、各自短板和可执行的 GEO 优化机会；不引入未被用户点名的委托方主体。
- 用户在前置问询中明确要求纳入自有机构时，即使该机构未被地区泛词查询发现，也要将其纳入统一评分和重点分析；不得人为加分，并明确区分自然发现结果与强制纳入。
- 摘要说明本次发现并核验了多少位 IP 名师，以及他们对机构可见性、实体关系和概念占位的主要影响。

## 2. 研究口径与边界

- GEO 定义与本报告不评价的事项。
- 公开网页代理观察与多引擎实测的实际采用情况；两类结果分表展示。
- 泛词查询、品牌词查询、自有媒体、外部自然引用的定义。
- 时间窗口、地域边界、语言、去重规则和主要局限。

## 3. 地区与考试生态

- 地区层级、主要城市和独立招录体系。
- 实际存在的考试、笔面试类型与培训决策场景。
- 本次查询矩阵如何据此适配；不适用问题如何剔除。

## 4. 查询矩阵与候选发现

- 按主题列出泛词／品牌词查询数量与代表问题。
- 说明调研发现对象、用户指定对象和补充对标对象的发现／选择逻辑。报告只使用“调研发现／用户指定／对标补充”等中文，不展示内部样本值。指定模式只包含用户点名主体；只有用户明确要求增加对标时才允许补充对标对象。
- 对证据不足或无法确认主体的处理方式。
- 地区模式说明候选池如何从整个地区的泛词查询中产生，以及领先机构如何按统一口径筛出；用户未点名机构时不得出现“用户指定”对象。
- 记录用户是否要求强制纳入自有机构。选择纳入时列明准确名称、别名核验与泛词命中情况；选择不纳入时不得出现“用户指定”对象。
- 说明 IP 名师如何从师资类泛词、机构页面、实名账号和独立来源中发现，以及进入正式分析的证据门槛。
- 指定模式列明用户点名的完整集合，报告不得自动加入其他机构或地区领先者；如有对标，必须注明用户的明确要求。

## 5. 证据地图

- A1/A2/B/C 来源数量、独立域名数和重复转载情况。
- 各机构自有媒体／外部自然引用结构。
- 关键实体关系和仍待核事项。

## 6. GEO 观察指数与排名

| 排名 | 机构 | 泛词覆盖度 /30 | 实体清晰度 /25 | 外部来源多样性 /20 | 概念占位度 /15 | 内容新鲜度 /10 | 总分 | 等级 | 证据置信度 |
|---:|---|---:|---:|---:|---:|---:|---:|---|---|
| 1 | {机构名称} |  |  |  |  |  |  |  |  |

主排名表不展示内部英文样本值。如果不同样本来源会影响读者理解，在方法或附录增加“入选方式”列，并使用“调研发现／用户指定／对标补充”。

低置信度或 60 分以下机构不解释 1—2 分和一两个名次的细小差异。若样本不可比，使用分组或“不足以排名”，不要强行给完整榜单。

地区模式下，主表优先展示排名靠前且证据充分的 5—10 家；其余主体放入附录或“待观察”组，不为凑全榜单制造精确名次。

用户明确要求强制纳入的自有机构即使未进入前 5—10，也必须保留在主表和重点分析中，并标明“用户要求纳入；本次泛词查询是否自然发现”。此说明不改变其得分或名次。

数据质量足够时生成：

1. `geo-index.png`：GEO 指数横向柱状图，注明观察日期与置信度。
2. `geo-quadrant.png`：实体可核验性 × 泛词覆盖度象限图；点大小可代表独立来源数。

图表数据必须来自 `scores.csv`，不得为视觉效果手工改分。数据不足时省略图表并说明原因。

## 7. 重点机构分析

对主排名中靠前且证据充分的机构逐家使用统一结构；地区模式不要求把所有发现对象都写成长篇分析：

### {机构名称}

- 实体识别：品牌、主体、创始人、老师/IP、课程、校区/基地。
- 泛词表现：在哪些泛词查询中自然出现，哪些仅为品牌词结果。
- 外部证据：独立来源、来源等级、独立域名和重复转载。
- 概念所有权：已建立的稳定关联与尚未占位的概念。
- GEO 模式：品牌权重型、查询铺量型、实体知识图谱型、名师 IP 型、地域实体型、主动 GEO 铺量型或证据支持的新模式。
- 五维得分解释：逐维说明证据，不只报总分。
- 风险与局限：机构自述、旧信息、实体歧义、证据不足。
- 证据置信度：高／中／低。

## 8. IP 名师 GEO 分析

名师分析与机构排名分开，不把人物和机构混在同一榜单。每位进入正式分析的老师使用统一结构：

| IP名师 | 关联机构 | 关系状态 | 主讲科目／产品 | 泛词自然命中 | 主要内容平台 | 概念占位 | 外部引用 | 证据置信度 |
|---|---|---|---|---:|---|---|---|---|
| {老师姓名} | {机构名称或关系待核} | {当前／历史／合作／待核} |  |  |  |  |  |  |

- 身份与别名：实名、稳定别名、账号及同名排除。
- 机构关系：任职、创始、合作、兼职、离职或待核，注明时间和证据。
- 专业关联：科目、课程、考试类型、地区和代表性内容。
- 自然发现：在哪些不含人名的师资或备考问题中出现。
- 内容与引用：自有账号、机构内容、独立来源及近一年更新。
- GEO 贡献：该人物是否帮助机构形成稳定的“机构—名师—科目—课程—地域”实体链。
- 风险边界：粉丝量、播放量和机构宣传称号不得直接证明教学质量，也不得直接提高机构排名。

没有达到证据门槛的老师进入“待核名师线索”，说明缺少身份、机构关系、科目绑定、近期内容或独立来源中的哪一项。

## 9. 区域竞争格局

- 全国品牌、本土综合机构、细分机构、老师/IP 型品牌和新主体的相对位置。
- 泛词覆盖、实体可核验性、外部多样性与地域占位的差异。
- 公开网页代理观察与真实多引擎采样结果如有差异，分别解释。

## 10. GEO 模式与实体图谱

- 汇总各机构模式，可多选，不强制一机构一类型。
- 展示核心实体链：品牌 → 主体 → 人物 → 科目/考试 → 产品 → 地域 → 外部引用。
- 区分已确认关系、机构自述关系和分析推断。

机会地图必须来自实际无结果、弱结果、实体歧义或概念归属不稳定的问题，不得写成普通搜索优化关键词清单。为每个 A/B 项给出可验证的查询、页面／实体动作与复测窗口。

## 12. 核心答案、局限与证据附录

- 用短答案回应用户最初的每个问题。
- 列出无法确认、需补采样或不宜比较的事项。
- 附查询清单、评分表、逐条证据、来源等级、访问日期和去重说明。
- 每个重要事实直接附可打开链接或证据编号；搜索摘要仅作线索，不进入最终事实链。

## HTML 默认交付

最终必须生成并直接交付自包含的 `report.html`，同时保留 `report.md` 和结构化 CSV 供审计。HTML 应内嵌必要样式，使用中文标题和表头，来源链接可点击，宽表格可横向滚动，并提供适合浏览器打印的样式。交付前在浏览器检查完整内容、中文字体、标题层级、表格、链接、裁切、重叠和黑块。未通过检查不得交付；不得只提供 Markdown、CSV 或“请用户自行导出”。

默认使用 `python3 scripts/generate_report_html.py <run-dir>` 生成 HTML，再运行 `python3 scripts/validate_run.py <run-dir> --strict`。最终校验默认要求 `report.html`；`--draft` 只允许在制作过程中跳过 HTML 门禁，不能作为完成或交付依据。

生成前核对摘要、正文和附录中的泛词／品牌词问题数、证据数、评分机构数和 IP 名师数与 CSV 完全一致；核对“用户指定”仅用于用户实际点名的对象。
