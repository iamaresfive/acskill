# 公考机构 GEO 调研报告模板 v2.0

## 标题与机器字段

```text
# 《{地区或范围}公考机构 GEO 与 AI 搜索可见性调研》

Schema版本：2.0
Skill版本：2.0
观察日期：{YYYY-MM-DD}
研究模式：{地区全景（regional-landscape）|单主体深挖（institution-deep-dive）|多主体比较（institution-comparison）|空白机会（gap-analysis）}
研究范围：{地区、城市、考试}
采样模式：{公开网页代理观察|多引擎实测}
Discovery问题数：{N}
Measurement问题数：{N}
Verification问题数：{N}
Discovery渠道覆盖：{以 | 分隔的内部渠道值}
漏项审计轮数：{N}
候选记录数：{N}
第一轮候选实体数：{N}
第二轮新增实体数：{N}
去重后实体数：{N}
正式评分数：{N}
待观察/证据不足数：{N}
证据数：{N}
IP名师调查：是
IP名师样本数：{N}
自有机构纳入：{是|否}
自有机构名称：{是时填写}
第二轮新增占比说明：{超过35%时填写}
免责声明：GEO 观察指数不代表教学实力、市场份额或大模型官方推荐排名。
```

紧接字段用一段话说明：公开网页代理与真实生成式引擎采样的差别；一次观察是快照；语料量不等于独立认可。

## 1. 执行摘要

- 直接回答区域内哪些主体可见性靠前、依据和主要短板。
- 写清 Discovery/Measurement/Verification 数量、候选数、评分数、证据数、名师数。
- 每条关键结论标证据编号与置信度。
- 不使用“教学最好”“市场第一”“官方推荐”等越界表述。

## 2. 研究范围与方法

- 地区、考试、城市、观察窗口和采样渠道。
- 三类查询的分工；强调只有 generic + Measurement 计入覆盖。
- 自有机构/用户点名/对标规则。
- 五维评分、证据分级和去重规则。

## 3. 候选覆盖审计

| 项目 | 第一轮 | 第二轮新增 | 冻结后 | 说明 |
| --- | ---: | ---: | ---: | --- |
| 候选记录 | | | | |
| 独立机构实体 | | | | |
| IP名师线索 | | | | |

按六条渠道列 Discovery 数量与代表问题；说明全国品牌、本土综合、细分机构、老师/IP 型、新主体和主要城市的覆盖情况。列出 merged、excluded、unresolved、evidence-insufficient 的主体及原因。第二轮新增率高时解释继续/停止依据。

## 4. 实体与证据地图

- 品牌—公司—老师—科目—产品—地域的已确认关系。
- 同名、简称、公司名、曾用名与历史噪声排除。
- A1/A2/B/C 数量、独立域名、同稿与同 URL 复核。
- A1 只支持对应陈述，不泛化为总体背书。

## 5. GEO 观察指数

### 领先与可解释组

| 机构 | 泛词覆盖 /30 | 实体清晰 /25 | 外部多样 /20 | 概念占位 /15 | 新鲜度 /10 | 总分 | 等级 | 证据置信度 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | --- | --- |

只在证据可比时排序。逐家解释五维证据和 Measurement 命中，不只报总分。

### 待观察／证据不足组（不分先后）

60 分以下、低置信度或实体关系不完整者在此分组；可以列分数供审计，但不强调一两个名次和 1—2 分差异。

## 6. Authority × Recall 诊断

| 象限 | 判定 | 典型主体 | 解释与动作 |
| --- | --- | --- | --- |
| 高权威 × 高召回 | 高质量证据充分，Measurement 命中高 | | 保持实体一致与更新 |
| 高权威 × 低召回 | 主体可信但非品牌问题少出现 | | 建立查询—页面覆盖 |
| 低权威 × 高召回 | 搜索常见但主要靠软文/聚合 | | 增加官方实体和独立外证 |
| 低权威 × 低召回 | 证据与自然发现均弱 | | 先补主体、别名和基础内容 |

“权威”依据来源等级、独立域名和实体关系证据；“召回”仅依据 Measurement。

## 7. IP 名师 GEO

名师与机构分表，不混入机构排名。记录姓名/别名、机构关系与时间、科目、产品、地区、平台、泛词命中、品牌核验、概念占位和证据置信度。粉丝量/播放量只作代理指标。

## 8. 重点主体分析

每家统一包含：入选方式（中文）、实体识别、Measurement 泛词表现、Verification 结果、外部证据、名师关系、概念占位、逐维得分理由、风险与优化动作。自有强制纳入或用户点名不得加分。

## 9. 竞争格局与机会地图

机会必须来自实际弱结果、无结果、同名污染或概念关系不稳。每个动作写目标问题、应补实体/页面/证据、验证指标和复测窗口。

## 10. 局限与核心答案

- 网页代理/真实 AI 边界；搜索地域与时间波动；未覆盖平台；人工评分权重。
- 无法确认、待补采样和不可比较项。
- 用 3—5 个短答案逐项回应用户最初问题。

## 证据索引与 HTML

正文关键事实使用 `[E001]`。生成器会从 `evidence.csv` 自动追加证据索引、锚点和可点击来源，因此 report.md 无需手工复制整张证据表。

最终执行：

```bash
python3 scripts/generate_report_html.py <run-dir>
python3 scripts/validate_run.py <run-dir> --strict
```

浏览器检查中文字体、标题层级、来源跳转、屏幕宽表横向滚动与 A4 打印分页。报告默认直接交付 HTML，Markdown 与 CSV 作为审计底稿保留。
