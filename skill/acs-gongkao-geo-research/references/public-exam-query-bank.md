# 公考 GEO v2.2 Query Bank

题池分两类：AI Answer Measurement 与 Discovery / Verification。两者不能混用。

## Institution AI Measurement

地区全景建议固定 16–24 题，覆盖：

- `{region}公考培训机构有哪些`
- `{region}本土公考机构推荐`
- `{region}省考培训机构推荐`
- `{region}省考笔试培训哪家好`
- `{region}省考面试机构推荐`
- `{region}事业单位培训机构推荐`
- `{region}选调培训机构推荐`
- `{region}申论培训机构推荐`
- `{region}行测培训机构推荐`
- `{region}一对一公考辅导推荐`
- `{region}线下公考班怎么选`
- `{region}公考选岗服务推荐`

根据当地考试生态增加城市、考试类型和面试形式，但固定后不要针对某个品牌改题。
