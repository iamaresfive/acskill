# 网页收录规范

阅读、概括和价值讨论默认只读；明确批准收录方案后才写库。

先取得可靠正文及实际覆盖范围，记录原始URL、标题、作者、发布日期和读取时间；按URL和标题查重，已有来源复用。动态页用适用浏览器或连接器，公众号使用当前可用专项工具，不指定开发者账号；权限、验证码或正文缺失如实报告，不用搜索摘要冒充原文。

方案列明归属、来源留存、命名、实名或脱敏、更新或新增页、冲突与关联。按目标库已确认目录保存来源，既有原件不改写；HTML、图片或附件只在任务授权及允许范围内归档，标明不完整部分。来源事实、作者观点、用户判断和Agent推断分开。

落盘后核对来源可追溯、索引和真实关联；新增原件且启用哈希模块时更新经审阅的基线并独立check。不自动公开、转发或上传到其他服务。
