# 知识库健康检查

健康检查默认只读，分结构信号和语义审查两层。

## 结构信号

脚本可自动检查：

- 重复文件 stem；
- 断掉的 Wiki Link 和行内 Markdown 文件链接（含图片）；
- 无法唯一确定目标的 Wiki 链接；
- 孤立 Markdown 页；
- 缺 frontmatter 的页面（仅作为信号，不代表一定错误）；

链接检查保留目录，支持 `.md` 后缀、URL 编码、带空格的尖括号路径，排除代码示例。Markdown 路径相对当前文件解析；Wiki 显式路径检查库根目录及当前目录，裸文件名先检查当前目录，再查全库唯一文件名。存在多个候选时报告歧义，不把它们都算作有效入链。

裸文件名 Wiki 链接也解析附件目录中的图片、PDF 等文件，例如 `![[chart.png]]`；同名附件仍报告歧义。附件参与链接解析，但不计入 Markdown 知识页数量。

当前脚本不验证标题锚点、引用式 Markdown 链接或远端网址；这些需要按任务人工复核。外部文件路径不作为库内有效链接。治理文件和索引位置由首次扫描工具识别。

## 语义审查

由 Agent 结合知识库规则判断：

- 疑似重复实体；
- 重要事实缺来源；
- 同主题碎片化；
- 当前结论与旧快照混淆；
- 项目状态矛盾；
- 来源事实、用户判断和 Agent 推断混写；
- 结构漂移；
- 原始材料疑似被覆盖。

## 风险级别

### Critical

原件异常、重大路径失效、索引整体错误、明显误合并等可能破坏知识完整性的情况。

### Warning

重复页面、来源不足、项目状态冲突、治理规则漂移。

### Suggestion

可合并主题、可补稳定关系、可建立索引等优化建议。

## 修复原则

Health Check 不等于 Fix。

先报告问题、证据、影响和建议，再由用户确认修复范围。高风险治理变化单独确认。
