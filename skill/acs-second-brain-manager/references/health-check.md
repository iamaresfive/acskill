# 知识库健康检查

健康检查默认只读，分结构信号和语义审查两层。

## 结构信号

脚本可自动检查：

- 重复文件 stem；
- 断掉的 Wiki Link；
- 孤立 Markdown 页；
- 缺 frontmatter 的页面（仅作为信号，不代表一定错误）；
- 治理文件和索引位置。

## 语义审查

由 Agent 结合知识库规则判断：

- 疑似重复实体；
- 重要事实缺来源；
- 同主题碎片化；
- 当前结论与旧快照混淆；
- 项目状态矛盾；
- 来源事实、用户判断和 Agent 推断混写；
- 结构漂移；
- 原始材料疑似被覆盖。

## 风险级别

### Critical

原件异常、重大路径失效、索引整体错误、明显误合并等可能破坏知识完整性的情况。

### Warning

重复页面、来源不足、项目状态冲突、治理规则漂移。

### Suggestion

可合并主题、可补稳定关系、可建立索引等优化建议。

## 修复原则

Health Check 不等于 Fix。

先报告问题、证据、影响和建议，再由用户确认修复范围。高风险治理变化单独确认。
