# 知识库治理初始化与适配 · v2.0

使用一次，将适合你的治理方案安装到自己的Markdown或Obsidian知识库。日常工作直接遵循库内AGENTS.md，无需每次调用本Skill。

安装名继续使用 `acs-second-brain-manager`。

| 场景 | 行为 |
| --- | --- |
| 新库 | 中文目录，按用途选择最小结构，生成规范与工具 |
| 已有库 | 只读理解后映射原结构，补齐或合并治理文件，不搬业务资料 |
| 再次运行 | 相同内容不重复，文件已变化则拒绝覆盖并报告冲突 |

基础包：AGENTS.md、结构约定、知识维护规范、模板、链接/索引检查、配置与说明。网页、多格式、项目记忆、协作、原件哈希按需选择。全部运行工具只需Python 3.10+标准库；旧v1 YAML校验另需PyYAML。

```text
请使用 acs-second-brain-manager 为这个知识库安装治理方案。
这是已有库，保留目录；先读现有规则并给出具体变更清单，确认后再落地。
```

新库默认目录：

```text
知识库/
├── AGENTS.md
├── 目录.md
├── 知识/
├── 原始材料/
├── 索引/知识全量索引.md
└── 规范与工具/
    ├── 规范/
    ├── 模板/
    └── 工具/
```

不会复制开发者业务、账号或路径，不生成旧式写锁与交接板。用户必须审阅并批准实际安装方案；程序指纹检查是乐观保护，不能替代同文件修改协调。
