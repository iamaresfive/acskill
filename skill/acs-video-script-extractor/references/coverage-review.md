# 长空缺复核

验收器会列出每个模型头部、内部、尾部超过15秒的无文字区间，并单列所有模型共同空缺。它不判断区间一定有对白。`--machine-only`允许结构通过并带候选警告；完整交付须核对声音或字幕并解释每个候选。

在输出目录写 `coverage-review.json`，只记录已经实际完成的核验，不为通过检查编造理由。原始raw不覆盖；确有漏段时在新目录补识别，并在校对稿及evidence记录对应文件、父文件时间偏移和采取的校正。

```json
{
  "source_sha256": "源视频的64位SHA-256",
  "input_sha256": {
    "large-v3": "raw-large-v3.json文件字节的64位SHA-256",
    "medium": "raw-medium.json文件字节的64位SHA-256"
  },
  "gaps": [
    {
      "model": "large-v3",
      "start": 1.0,
      "end": 599.0,
      "status": "silence",
      "reason": "填写本区间实际复核结论",
      "evidence": "填写核对的声音/字幕区间或补识别结果位置"
    }
  ]
}
```

两个模型同一区间分别记录；起止时间按候选输出填写。status只支持silence（静音）、non-speech（音乐等无对白）、corrected（已补识别并校对）。reason与evidence必须非空。模型原稿变化或新增模型后须重新核验，旧记录哈希不符会失败。

自动校验仅检查记录、哈希和覆盖，不证明描述的证据真实；执行者仍须实际复核。已经解释的空缺会继续显示候选信息，不能把曾有空缺隐去。
