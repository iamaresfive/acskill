# 使用案例

## 案例 1：完整提取一条本地短视频

用户：

```text
请把这个 MP4 里的文案完整提出来。
不要上传任何云端服务，尽量把人名和数字核准。
```

处理：

1. probe 媒体；
2. large-v3 + medium 双模型转写；
3. 比较差异并标记数字、否定词、一侧缺文等高风险点；
4. 视频有字幕时抽帧复核；
5. 生成校对逐字稿、忠实整理稿和疑点清单；
6. 完整验收后交付。

## 案例 2：一小时访谈

用户：

```text
这是一个一小时访谈，帮我完整转写。
不要为了可读性删掉有意义的口语表达。
```

处理重点：

- 不因视频长就只截取前半段；
- 转写过程中保留可见进度；
- 检查末段距媒体结尾是否异常；
- 校对稿保留原有问答顺序和重要语气；
- 忠实整理稿才清理无意义重复。

## 案例 3：纯音频

用户：

```text
这是 M4A，没有画面。帮我提取完整逐字稿。
```

处理：

- 正常执行 probe、双模型转写和差异比较；
- 明确“纯音频，无法进行字幕画面复核”；
- 对人名、数字等无法仅靠声音确定的内容列入疑点，而不是猜。

## 案例 4：用户只要发布稿

用户：

```text
把这个视频改成一篇更适合发朋友圈的文案。
```

如果来源还没有可靠转写，先完成来源层：

```text
原始模型转写 → 校对逐字稿 → 忠实整理稿
```

之后再另建：

```text
文案-优化稿.md
```

优化稿可以重写，但不得覆盖前面的来源文件。

## 案例 5：只有网络链接

用户：

```text
把这个抖音链接里的视频文案提出来。
```

本 Skill 不负责主动下载网络视频。先通过用户允许的其他下载 / ingest 流程得到本地文件，再进入本地转写链路。
