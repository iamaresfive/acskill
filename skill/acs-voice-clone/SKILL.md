# 本人声音克隆配音

只负责文案到合成旁白。使用本地 Qwen3-TTS Base 和 MLX Audio，默认声音配置为 `self`。模型、环境及声音工作副本放在本机独立目录，不随 Skill 分发；生成文件使用用户指定的独立输出目录。复用已有环境，不为每次配音重复安装或下载。

## 使用边界

- 本仓库不提供任何人的声音或授权。首次使用须确认声音主体、参考录音及明确同意的范围并登记本机配置。用户明确要求“用我的声音配这段”且已有有效授权记录时可沿用，不每段重复确认；仅讨论声音或询问方法不触发生成。文稿未定可做试听，但不得称为定稿。
- 配置中保存的是既有授权参考片段，不保证等同于新窗口刚收到的录音。用户明确指定新样本时先核对样本身份与对应文字，再按需登记新配置；不静默替换默认声音。第三人的声音须有该声音主体的明确授权。
- 不自动上传、调用云端克隆、读凭证、发消息、发布或入库；不改原录音和原始材料，不把合成旁白称为本人实录。不用于冒充他人或规避身份验证。
- 已验证环境为 Apple Silicon + Python 3.12；不承诺其他平台兼容。依赖或模型缺失时报告缺项与初始化方法；不自动安装、联网或改成另一音色。

## 日常执行

脚本路径相对于本 Skill 根目录；从当前工作区用绝对脚本路径调用，无须切换工作区。

1. 先读用户提供的完整文稿。保留原文，疑似人名或事实错字不猜改。准备 UTF-8 文本，空行分段；较长段落脚本会按句切分。需要固定段落、读音替换时用下面的 JSON。
2. `python3 scripts/voice_clone.py doctor` 查看环境和已登记声音。正常复用即可；首次初始化或故障恢复读 [运行环境与输入说明](references/runtime.md)。
3. `python3 scripts/voice_clone.py generate --input /绝对路径/文稿.txt --output-dir /绝对路径/独立配音任务 --authorized`。`--authorized` 仅在本次确有配音授权时传入。
4. 相同输入与参数再次运行会校验并复用已完成片段；`--redo s02` 只重做指定段（ID以 manifest 为准），保留旧片段文件。若改了文稿或参数，使用新的输出目录，不覆盖旧任务。
5. 生成后跑 `python3 scripts/verify_voice.py --job /绝对路径/输出目录`，利用已有本地 Whisper 检查说出的文字；若安装在另一环境，传 `--python /Whisper环境/bin/python`。它是漏字、错读、重复的机器筛查，不证明音色相似、语气自然或已人工听完。短试听及问题片段应试听；无法听验时明确说明。长篇只重做有问题的段落，不无故整篇重跑。
6. 交付 `旁白.wav` 和简短状态；需要字幕或剪辑时再使用 `timeline.json`，它只有实际段落时长，不是词级字幕。所有合成音频均标为本人授权的 AI 合成。用户未要求时不额外做视频、发布包或归档。

显式分段输入：

```json
{
  "segments": [
    {"id": "s01", "text": "今天聊聊AI。", "spoken_text": "今天聊聊 A I。"},
    {"id": "s02", "text": "招生只是开始，交付才是关键。"}
  ]
}
```

`spoken_text` 仅用于读音处理，不能偷改观点；与原文一起保存。人名、多音字、数字、缩写优先短句试听，不建立未经确认的永久替换字典。

## 输出与验收

- `input.json`：原文与实际送入模型的文字；`manifest.json`：声音/模型/输入指纹、种子、片段文件与完成状态。
- `takes/`：独立 WAV 片段；`旁白.wav`：单声道 24 kHz PCM16 合成旁白；`timeline.json`：按真实音频长度加段间停顿得到的时间轴。
- `quality.json`：波形、音量、时长、生成上限检查。`asr-review.json`：转写、文字差异及待听位置。生成失败或校验未通过时不能称整篇完成。
- 同一运行目录内的生成任务串行使用模型资源；发现占用即返回“忙”，不后台无限等待。该保护不协调其他软件或另一运行目录的 GPU 任务。
- 音色/自然度最终由用户试听判断；本 Skill 不训练新模型，也不承诺与本人声音完全一致。
