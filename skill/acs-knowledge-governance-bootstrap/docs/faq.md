# 常见问题

**日常还要调用吗？** 不需要，目标库自己的AGENTS、规范和工具接续工作。宿主须支持读取工作区规则，否则明确让Agent读AGENTS。

**已有英文目录会改中文吗？** 不会。中文目录是新库初始化默认；接管保留现状。

**会搬文件、覆盖规则吗？** 不搬业务文件；AGENTS保留原文并审阅合并区，同名自定义规则冲突时拒绝覆盖。

**所有模块都要装吗？** 不要。按需要选择网页、文件、项目、协作、原件哈希、工作文件分类和中转站。两个工作模块默认关闭，互不依赖。

**能自动生长吗？** 规则要求获授权后查重、更新、合并、维护真实关联；不运行后台任务。

**已经有其他治理配置怎么办？** 先读取已有规则并比较适配方案，保留既有目录和用户修改，不重复安装同类规则。

**跟我的原规则冲突怎么办？** Agent分别核对知识库管理、工作文件夹、工作产出和中转站，说明原规则、冲突、整改建议及影响。你明确同意具体方案后才改；未同意保持原样，不以安装授权代替整改授权。

**装好就一定照着运行吗？** 要让实际使用的Agent读取库内入口，并验证它能按规则处理任务。支持自动读取的核对工作区；不支持的显式引用入口或按授权设置项目指令。未验证的宿主不能宣称已生效。

**检查通过意味着什么？** 仅代表声明的结构范围通过，事实、语义冲突与权限需要人工核验。

**要自己填写JSON吗？** 不用，聊天确认模块和路径，Agent生成配置供核对。

**开中转站会自动通知其他Agent吗？** 不会。它提供文件位置与交接规则，不提供通知、同步或权限共享；直接转贴同样有效。

**工作目录会立即建好或搬旧文件吗？** 安装只保存规则和配置，任务需要时按授权建文件夹。历史迁移、清理和Agent软件配置另外确定。
