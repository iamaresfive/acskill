# 常见问题

**日常还要调用吗？** 不需要，目标库自己的AGENTS、规范和工具接续工作。宿主须支持读取工作区规则，否则明确让Agent读AGENTS。

**已有英文目录会改中文吗？** 不会。中文目录是新库初始化默认；接管保留现状。

**会搬文件、覆盖规则吗？** 不搬业务文件；AGENTS保留原文并审阅合并区，同名自定义规则冲突时拒绝覆盖。

**所有模块都要装吗？** 不要。按需要选择网页、文件、项目、协作、原件哈希。

**能自动生长吗？** 规则要求获授权后查重、更新、合并、维护真实关联；不运行后台任务。

**原管理器怎么办？** 原 `acs-second-brain-manager` 独立保留；使用本技能时先比较适配方案，不删除其既有目录和用户修改。

**检查通过意味着什么？** 仅代表声明的结构范围通过，事实、语义冲突与权限需要人工核验。
