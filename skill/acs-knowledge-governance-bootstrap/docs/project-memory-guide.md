# 专项记忆使用说明

专项记忆适合需要跨多次对话持续推进的项目。它不是聊天摘要，也不是任务清单，而是一份让新对话快速接手项目的“当前上下文入口”。

- 规范全文：[专项记忆规范](../references/project-memory.md)
- 可复制模板：[专项记忆模板](../templates/project-memory.md)

## 什么时候值得用

符合下面任意两项，通常就值得考虑：

- 项目会跨越多天或多周；
- 需要在不同对话中继续；
- 已经形成多个关键决策；
- 项目有阶段、卡点和多份关键文件；
- 用户不希望每次重新解释背景。

一次性写作、图片生成、简单转换或几步就能完成的任务，通常不需要专项记忆。

## 5 分钟开始

### 1. 让 Agent 先判断现有结构

```text
请检查这个项目是否已经有项目页、任务台账或专项记忆。先只读，不要创建重复入口。
```

### 2. 明确授权创建

```text
这是一个会跨多次对话推进的长期项目。请按专项记忆规范创建一份专项记忆，使用公开模板，先读取现有项目文件，再填写真实状态；不确定的信息标待核。
```

推荐文件名：

```text
[项目简称] 专项记忆.md
```

### 3. 换新对话时恢复

```text
继续“项目全名”。请先读取对应专项记忆和其中列出的当前权威文件，再告诉我现在的阶段、卡点和下一步。不要把旧记忆当成新的写入授权。
```

### 4. 有实质变化后更新

```text
这个阶段已经完成，新的决定是……。请更新专项记忆中的当前状态、进展、下一步和关键决策；不要把详细任务重复抄进专项记忆。
```

## 怎么填写

### 一句话状态

这是新对话最先看的内容。建议写清：

```text
当前阶段 + 已经确定的关键结果 + 最大卡点 + 接下来要做什么
```

不要只写“正在推进”“持续优化”这类无法接手的空话。

### 关键决策

只记录真正改变方向、范围、架构或执行规则的决定，并写出理由和影响。普通口头确认、临时想法和完整讨论过程不必保留。

### 当前文件结构

优先使用知识库内相对路径或现有链接格式。不要把用户名、本机绝对路径、内网地址和临时目录写进准备公开分享的文件。

### 进行中与下一步

如果已有任务台账：

- 专项记忆只保留项目级目标、依赖和关键节点；
- 负责人、截止日期、逐项状态与验收留在台账；
- 在专项记忆中链接台账，不做两份同步维护。

## 日常维护节奏

只在状态、决定、卡点或下一步真的变化时更新。同一批变化集中更新一次。

建议定期检查：

- 一句话状态是否还是当前事实；
- 下一步是否具体、可验证；
- 已完成是否堆积过多；
- 关键决策是否已有过时内容可归档；
- 链接是否仍指向现场权威文件；
- 待核事项是否已经解决。

文件接近 500 行时先压缩：删重复、精简状态、把旧决策移入归档。压缩后仍妨碍接手，再按月份归档。

共用归档目录时使用 `归档/项目简称-专项记忆-历史-YYYYMM.md`，避免不同项目同月归档重名。同项目同月向现有归档补充，不覆盖旧内容。

## 专项记忆不是什么

- 不是每日工作日志；
- 不是全部任务明细；
- 不是原始材料的替代品；
- 不是未经确认即可继续写入或对外操作的授权；
- 不是项目现场的绝对真相：当前文件与用户最新确认优先。

## 公开分享前的脱敏清单

真实专项记忆通常不适合原样上传公开仓库。分享前检查：

- [ ] 姓名、联系方式、账号和身份信息已删除或替换；
- [ ] 客户、员工、合作方和未公开项目名已泛化；
- [ ] 本机绝对路径、内网地址和内部系统名已移除；
- [ ] Token、Cookie、密钥和仓库凭证不存在；
- [ ] 金额、合同、经营数据和内部评价已移除或取得发布许可；
- [ ] 示例无法通过组合信息反推出真实主体；
- [ ] 链接只指向准备一同公开的文件或公开网址。

这份仓库中的规范和模板已经按上述原则公开化处理，不包含开发者的真实专项记忆内容。

正文脱敏不等于 Git 历史匿名：提交的作者及提交者邮箱也会进入历史。公开前检查 `git log --format=fuller`，后续提交可使用 GitHub 账号设置中的隐私邮箱。修改本地 Git 邮箱仅影响新提交；清理已发布历史需要另行评估历史重写和协作者同步范围。

## 验收问题

创建或更新后，找一个不了解历史的人或新的 Agent 只读这份文件，确认它能回答：

1. 项目是什么、不是什么？
2. 现在到哪一步？
3. 当前卡点是什么？
4. 哪些重要决定已经确定，原因是什么？
5. 应该先看哪些现场文件？
6. 下一步具体做什么？
7. 哪些信息仍然待核？

七项都能回答，专项记忆才真正发挥了作用。
