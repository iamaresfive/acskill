# 使用案例

## 新库

“帮我建立研究与项目知识库，中文目录，主要由我当前的Agent维护，需要长期项目记忆。”

建议知识、原始材料、索引、规范与工具；选择projects。确认后落地，业务主题等实际资料出现后再建，不预制开发者行业分类。

## 已有库

“Notes、Projects、Attachments已经在用，Index.md是索引，保留现状，补来源保护和写后检查。”

配置映射原目录和索引，阅读原AGENTS及Rules，审阅合并；可选source-hashes，不把Notes改名。

## 后续升级

“多人开始协作，加协作规则。”

比较已有规范，选择主要维护者与临时授权边界，不建立active/idle锁。完整批准升级清单后合并；不会顺手改业务页。
