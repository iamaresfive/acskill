# 公开发布检查

公开 Skill 使用当前使用者授权和用户选择的路径，不绑定作者的真实姓名、私人账号、个人知识库或内部 Agent 身份。发布前检查正文、模板、脚本、测试样例、附件和提交身份；不能只检查 SKILL.md。

本仓库提交使用 GitHub 用户名及 GitHub 提供的 noreply 邮箱。请在仓库级 Git 配置中设置自己的公开身份，不要直接复制他人的姓名或邮箱。

暂存拟发布内容后运行：

```sh
python3 scripts/check_public_privacy.py
```

检查器读取暂存区与本地分支历史，仅报告文件位置和风险类型，不打印凭据。CI 在推送和 PR 时执行相同检查；失败不会自动撤回已经公开的提交，因此本地检查必须先做。占位路径使用 `/Users/xxx/`、`/home/user/` 或用户显式传入的参数。规则命中应人工确认，不能通过编码隐藏真实信息。

自动检查不能发现所有个人信息，也不能替代人工审查；公开来源引用和通用示例不应机械删除。仓库外的内部工作规则、真实资料、账号和凭据不要复制进公开包。

历史清理后，旧克隆不得直接合并或推回旧历史。先保留尚未提交的工作，再重新克隆；确需迁移改动时逐项审查后移植。旧提交链接和旧 PR 引用可能仍可访问，是否清除 GitHub 缓存与 PR 引用须通过 GitHub Support 核实。第三方已下载的副本无法由仓库维护者远程删除。
