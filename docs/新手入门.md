# acskill 新手入门

这里有三个给 AI 用的工具。先选你要做的事，再把对应提示词和真实资料交给 AI。

## 先选哪个工具

| 你想做什么 | 使用哪个 Skill |
| --- | --- |
| 给知识库建立目录和管理规则 | 知识库初始化 · `acs-knowledge-governance-bootstrap` |
| 把本地音视频整理成文字 | 音视频文字提取 · `acs-video-script-extractor` |
| 用本人授权声音给文案配音 | 本人声音克隆配音 · `acs-voice-clone` |

知识库先用初始化工具建立或补齐管理规则。装好以后，日常查询、入库和更新都让 AI 读取库内 AGENTS.md，按已有规则执行。规范、工具和自有 Skill 的正式内容保存在库里，换 Agent 时沿用，不用重新整理。

## 使用前准备

你的 AI 工具需要能读取本地文件、执行命令，并加载或明确读取 Skill。只会网页聊天、不能操作本机的 AI，不能靠一个链接完成本机安装。

第一次先把下面的话交给 AI：

```text
请阅读 https://github.com/iamaresfive/acskill
我想做的是：【填写你的需求】。
请先检查当前客户端能否读取本地文件、执行命令、发现Skill，再选择本次需要的单个Skill。
把该Skill完整包保存在我的知识库工具目录或我指定的独立目录，保留脚本、模板和参考资料；按客户端支持的方式引用或安装，不把整个仓库当作一个Skill。
安装后让我重新加载或新建会话，核对你能否读到SKILL.md和所需资源，并做一次不改业务数据的最小检查。
缺少软件、依赖或模型时，先列出补齐方式；按我已有授权处理，超出范围的下载、费用或配置变动再确认。不能完成的部分直接说明。
```

完成时请 AI 给你三样东西：正式包位置、客户端如何引用它、最小检查结果。换 Agent 时沿用完整包，重新适配入口即可。

**三件事分开看：**安装 Skill 是让 AI 读到工作说明；知识库初始化是把规则应用到自己的库；配音初始化是准备本机运行环境。完成第一件不代表后两件也完成。

## 一、知识库初始化

把目录、管理规则和检查工具装进你的知识库。新库默认用中文目录；已有库保留原来的目录、命名和资料。

### 第一次怎么用

如果你还没有知识库，先准备一个空文件夹，再把实际路径和用途告诉 AI：

```text
请使用 acs-knowledge-governance-bootstrap 为我建立知识库管理规则。
知识库路径：【填写已创建的空文件夹路径】。
主要用途：【填写你的用途】。
请先给我看目录、规则和工具的具体方案，等我确认后再安装。
```

如果已经有资料和目录：

```text
请使用 acs-knowledge-governance-bootstrap 为这个已有知识库补齐管理规则。
知识库路径：【填写实际路径】。
保留现有目录、命名和业务资料，先读取已有规则。
请列出需要新增、合并和保留的内容，等我确认后再安装。
```

### 接下来会发生什么

1. AI 先了解你的用途和现有文件。
2. 给你看要增加或合并哪些规则、模板和工具。
3. 你确认后再安装，并检查结果。

### 装好以后怎么用

日常直接告诉 AI：

```text
请先读取这个知识库的 AGENTS.md，并按库内规则完成我的任务：【填写任务】。
```

不必每次重新调用初始化工具。需要调整管理规则时，再让 AI 使用初始化工具评估升级。

[详细说明](../skill/acs-knowledge-governance-bootstrap/README.md) · [快速开始](../skill/acs-knowledge-governance-bootstrap/docs/quick-start.md) · [常见问题](../skill/acs-knowledge-governance-bootstrap/docs/faq.md)

### 平时怎么交任务

| 你要做什么 | 可以直接对 AI 说 |
| --- | --- |
| 查以前的资料 | 我以前对这个问题有哪些记录？请附上来源。 |
| 把新资料存进来 | 把这份资料入库，先查重、检查冲突，给我看准备怎么改。 |
| 更新项目情况 | 根据这份最新反馈，更新项目当前情况，保留原始来源。 |
| 检查矛盾 | 这条信息和以前的记录有没有冲突？先不要修改。 |
| 给知识库做体检 | 检查断链、重复和缺来源的问题，只报告，不自动修复。 |

查询默认只读。写入默认先说明变更方案，确认后执行；已经明确授权的任务可以在约定范围内继续。删除、大规模搬文件或改变管理规则，需要另行确认。

## 二、音视频文字提取

把本地课程、访谈、会议或短视频整理成文字，采用“自动转写＋AI／人工复核”。支持 MP4、MOV、MP3、M4A、WAV 等本地文件；机器结果还要核对人名、数字和漏段。

### 第一次怎么用

```text
请使用 acs-video-script-extractor 处理这个本地音视频文件：【填写文件路径】。
先检查Python、faster-whisper、FFmpeg，以及large-v3和medium两种兼容模型能否离线读取；报告实际环境与模型位置。
缺少时给出补齐方式、下载来源和所需空间，在我授权范围内准备；准备好后先跑短样例。
准备好后，全程离线做双模型转写，再复核差异；如果视频有可见字幕，结合字幕画面校对。
最后给我完整校对逐字稿、还原整理稿和待确认疑点。
```

### 需要准备什么

本机需要 Python、faster-whisper、FFmpeg / ffprobe，以及已缓存的 Whisper 模型，默认是 `large-v3` 和 `medium`。让 AI 按[快速开始](../skill/acs-video-script-extractor/docs/quick-start.md)检查即可。

执行转写时不会自动联网安装依赖或下载模型，需要提前准备好。它处理本地文件，不会自动下载网络视频。

### 你会得到什么

- **校对逐字稿**：尽量完整保留原话，并核对识别差异。
- **还原整理稿**：去掉口头噪声，让内容更容易读，保留原意。
- **待确认疑点**：列出无法可靠确定的人名、数字等内容。

如果还要改成短视频口播稿或朋友圈文案，在确认来源稿后，再单独提出创作要求。

## 三、本人声音克隆配音

用本人的授权声音为文案生成中文旁白。当前已验证 Apple Silicon Mac；需要可运行的 MLX／Qwen3-TTS 本地环境和模型。本包的初始化脚本复用已有环境，不是从零自动装齐的一键安装器。

第一次可以这样说：

```text
请使用 acs-voice-clone，先检查我是否具备Apple Silicon、可运行的MLX／Qwen3-TTS环境和完整本地模型。
已有环境就复用；缺少时先给准备方案和官方来源，按我的授权补齐，不把“Skill已安装”说成“配音环境已就绪”。
我会提供本人明确同意使用的3至30秒录音和逐字对应文字；请检查或按授权转换音频格式，条件齐全后再初始化。
准备好后，用我的文案做短句试听，不上传、不发布。
```

已有声音配置后，直接说“用我的声音配这段文案”。输出包括完整 WAV、各段音频和段落时间轴；可以只重做一段，不必整篇重跑。文字核对使用已有本地 Whisper，机器通过仍不替代试听和 AI 合成标识。

尚无配音环境时，先完成依赖与模型准备，再回来初始化；下载了仓库不代表能立即配音。其他系统、芯片和版本需要另行验证。

[详细说明](../skill/acs-voice-clone/README.md) · [环境与初始化](../skill/acs-voice-clone/references/runtime.md)

## 四、需要时，把音视频结果存进知识库

先让音视频工具完成转写和校对，确认结果后，再交给知识库处理。

知识库已经有管理规则时，把下面的话交给 AI：

```text
请读取知识库的 AGENTS.md，按库内规则把这次校对后的访谈资料入库。
先查重、检查信息冲突，给我看具体变更方案。
```

音视频工具不会自动入库。这一步在你确认来源内容之后单独进行。
