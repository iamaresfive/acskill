# acskill 新手入门

这里有三个给 AI 用的工具。先选你要做的事，再把对应提示词和真实资料交给 AI。

## 先选哪个工具

| 你想做什么 | 使用哪个 Skill |
| --- | --- |
| 给知识库建立目录和管理规则 | 知识库初始化 · `acs-knowledge-governance-bootstrap` |
| 日常查资料、入库、更新项目情况 | 第二大脑管理器 · `acs-second-brain-manager` |
| 把本地音视频整理成文字 | 音视频文字提取 · `acs-video-script-extractor` |

**两个知识库工具可以独立使用，不用都装。**

- 想先建好目录、规则和检查工具：选初始化工具，安装后让 AI 按库内规则工作。
- 想让 AI 持续查资料、入库和更新：选管理器。它会先了解已有结构，沿用已有规则。
- 已经在用管理器：可以继续用，不必重新初始化。以后需要补齐规则，再单独评估。

## 使用前准备

你的 AI 工具需要支持加载 Skill、访问本地文件和执行相应命令。若还没安装，把下面的话交给 AI：

```text
请阅读 https://github.com/iamaresfive-code/acskill
我想做的是：【填写你的需求】。
请帮我选择合适的 Skill，检查当前工具和电脑环境是否支持，并指导我安装和使用。
```

安装好需要的 Skill 后，按下面对应的一节开始。

## 一、知识库初始化

把目录、管理规则和检查工具装进你的知识库。新库默认用中文目录；已有库保留原来的目录、命名和资料。

### 第一次怎么用

如果你还没有知识库，先准备一个空文件夹，再把实际路径和用途告诉 AI：

```text
请使用 acs-knowledge-governance-bootstrap 为我建立知识库管理规则。
知识库路径：【填写已创建的空文件夹路径】。
主要用途：【填写你的用途】。
请先给我看目录、规则和工具的具体方案，等我确认后再安装。
```

如果已经有资料和目录：

```text
请使用 acs-knowledge-governance-bootstrap 为这个已有知识库补齐管理规则。
知识库路径：【填写实际路径】。
保留现有目录、命名和业务资料，先读取已有规则。
请列出需要新增、合并和保留的内容，等我确认后再安装。
```

### 接下来会发生什么

1. AI 先了解你的用途和现有文件。
2. 给你看要增加或合并哪些规则、模板和工具。
3. 你确认后再安装，并检查结果。

### 装好以后怎么用

日常直接告诉 AI：

```text
请先读取这个知识库的 AGENTS.md，并按库内规则完成我的任务：【填写任务】。
```

不必每次重新调用初始化工具，也不必额外安装管理器。需要调整管理规则时，再让 AI 使用初始化工具评估升级。

[详细说明](../skill/acs-knowledge-governance-bootstrap/README.md) · [快速开始](../skill/acs-knowledge-governance-bootstrap/docs/quick-start.md) · [常见问题](../skill/acs-knowledge-governance-bootstrap/docs/faq.md)

## 二、第二大脑管理器

用于持续管理本地 Markdown / Obsidian 知识库：查询旧资料、整理新资料、更新项目情况、检查信息冲突。

### 第一次怎么用

```text
请使用 acs-second-brain-manager 接管这个知识库。
知识库路径：【填写实际路径】。
这是一个已有库，第一次先只读扫描，不要修改文件。
告诉我你理解的目录结构、现有规则，以及还需要我确认的地方。
```

AI 先了解目录、索引、原始资料和已有规则。你确认或纠正后，再交给它具体任务。

如果你还没有知识库，想先把目录和规则装好，请看上一节“知识库初始化”。管理器本身也能提出新库结构方案；已经选择这条路径的人可以继续使用，不需要重复安装另一套规则。

### 平时怎么交任务

| 你要做什么 | 可以直接对 AI 说 |
| --- | --- |
| 查以前的资料 | 我以前对这个问题有哪些记录？请附上来源。 |
| 把新资料存进来 | 把这份资料入库，先查重、检查冲突，给我看准备怎么改。 |
| 更新项目情况 | 根据这份最新反馈，更新项目当前情况，保留原始来源。 |
| 检查矛盾 | 这条信息和以前的记录有没有冲突？先不要修改。 |
| 给知识库做体检 | 检查断链、重复和缺来源的问题，只报告，不自动修复。 |

查询默认只读。写入默认先说明变更方案，确认后执行；已经明确授权的任务可以在约定范围内继续。删除、大规模搬文件或改变管理规则，需要另行确认。

[详细说明](../skill/acs-second-brain-manager/README.md) · [快速开始](../skill/acs-second-brain-manager/docs/quick-start.md) · [使用案例](../skill/acs-second-brain-manager/docs/examples.md) · [专项记忆使用说明](../skill/acs-second-brain-manager/docs/project-memory-guide.md)

## 三、音视频文字提取

把本地课程、访谈、会议或短视频整理成文字。支持 MP4、MOV、MP3、M4A、WAV 等本地文件。

### 第一次怎么用

```text
请使用 acs-video-script-extractor 处理这个本地音视频文件：【填写文件路径】。
先检查依赖和本地模型是否齐全；缺少时告诉我需要准备什么。
准备好后，全程离线做双模型转写，再复核差异；如果视频有可见字幕，结合字幕画面校对。
最后给我完整校对逐字稿、还原整理稿和待确认疑点。
```

### 需要准备什么

本机需要 Python、faster-whisper、FFmpeg / ffprobe，以及已缓存的 Whisper 模型，默认是 `large-v3` 和 `medium`。让 AI 按[快速开始](../skill/acs-video-script-extractor/docs/quick-start.md)检查即可。

执行转写时不会自动联网安装依赖或下载模型，需要提前准备好。它处理本地文件，不会自动下载网络视频。

### 你会得到什么

- **校对逐字稿**：尽量完整保留原话，并核对识别差异。
- **还原整理稿**：去掉口头噪声，让内容更容易读，保留原意。
- **待确认疑点**：列出无法可靠确定的人名、数字等内容。

如果还要改成短视频口播稿或朋友圈文案，在确认来源稿后，再单独提出创作要求。

[详细说明](../skill/acs-video-script-extractor/README.md) · [快速开始](../skill/acs-video-script-extractor/docs/quick-start.md) · [使用案例](../skill/acs-video-script-extractor/docs/examples.md) · [常见问题](../skill/acs-video-script-extractor/docs/faq.md)

## 四、需要时，把音视频结果存进知识库

先让音视频工具完成转写和校对，确认结果后，再交给知识库处理。

如果你使用第二大脑管理器：

```text
请使用 acs-second-brain-manager 把这次校对后的访谈资料入库。
先查重、检查信息冲突，给我看准备新增或更新哪些内容。
```

如果你只安装了知识库管理规则：

```text
请读取知识库的 AGENTS.md，按库内规则把这次校对后的访谈资料入库。
先查重、检查信息冲突，给我看具体变更方案。
```

音视频工具不会自动入库。这一步在你确认来源内容之后单独进行。
