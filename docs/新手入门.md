# 新手入门

仓库提供两个独立Skill。

## 知识库治理初始化与适配

使用 `acs-second-brain-manager` v2.0，将治理方案落地到你自己的知识库。

```text
请为我的知识库安装治理方案。新库目录用中文；如果已有资料，就保留现有结构。
先了解用途，给出AGENTS、必要规范和工具的具体清单，确认后执行。
```

安装后日常遵循库内AGENTS，不需要重复调用。详见[治理快速开始](../skill/acs-second-brain-manager/docs/quick-start.md)。

# 二、本地视频文案：`acs-video-script-extractor`

如果你有本地 MP4、MOV、M4A、MP3 等文件，想把内容完整提取出来，又不想只依赖一次语音识别，可以使用这个 Skill。

它的默认流程是：

```text
媒体预检
→ 双模型离线转写
→ 差异对齐与风险分级
→ 有字幕时抽帧复核
→ 校对逐字稿
→ 还原文案整理
→ 待确认疑点
→ 完整验收
```

## 第一次怎么用

最简单直接说：

```text
请使用 acs-video-script-extractor 处理这个本地视频。
全程离线，先做双模型转写，再校对高风险差异；如果视频有可见字幕，结合字幕画面复核。
最后给我完整逐字稿、还原整理文案和待确认疑点。
```

然后提供本地文件。

默认不会：

- 把源视频上传飞书妙记或其他云端转写服务；
- 自动从网络链接下载视频；
- 自动把结果写进第二大脑；
- 为了让文案“更好看”而偷偷补观点、案例、数据或结论。

## 你会得到什么

机器阶段会保留：

```text
source-probe.json
run-manifest.json
raw-large-v3.json
raw-medium.json
review-points.json
review-frames/（视频有字幕且需要时）
```

最终会得到：

```text
逐字稿-校对版.md
文案-还原整理版.md
待确认疑点.md
```

三个文件角色不同：

- **校对逐字稿**：回答“原视频到底说了什么”；
- **还原整理稿**：回答“在不改变原意的前提下，去掉口头噪声后怎样更容易读”；
- **疑点清单**：回答“还有哪些关键地方不能可靠确定”。

如果你后面还要朋友圈稿、短视频口播优化、标题等，再在来源稿基础上另做创作版本。

## 为什么不是跑一次 Whisper 就结束

因为单模型最容易把这些地方悄悄听错：

- 人名；
- 机构名；
- 数字和日期；
- 英文专名；
- “会 / 不会”“有 / 没有”这类否定关系。

双模型的作用不是投票，而是把差异暴露出来。差异点会被风险分级，有成片字幕时再结合字幕画面检查。

## 环境准备

本机需要：

- Python；
- `faster-whisper`；
- FFmpeg / ffprobe；
- 已缓存的本地 Whisper 模型，默认 `large-v3` + `medium`。

Skill 执行时不会自动联网安装依赖或下载模型。

# 三、两个能力如何衔接

先用治理初始化Skill安装本库规则。以后本地视频由视频Skill转写，用户确认入库后，直接按库内AGENTS与收录规范处理，不必再次调用初始化Skill。
